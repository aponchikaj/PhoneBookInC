# 📒 PhoneBook in C

A command-line phonebook application written in C. One of my earliest projects — built to learn memory management, structs, and file I/O in C.

> ✍️ Written at **age 15** (2026)

---

## Features

- Add, search, edit, and delete contacts
- Persistent storage via file I/O
- Console-based UI with menu navigation
- Struct-based data modeling for contacts

---

## Tech

- **Language:** C
- **Concepts used:** structs, pointers, file I/O (`fopen`, `fread`, `fwrite`), dynamic memory (`malloc`, `free`)

---

## How to Run

```bash
gcc phonebook.c -o phonebook
./phonebook
```

---

## What I Learned

This was my first real encounter with manual memory management and persistent data storage without any framework. Writing in C from scratch — no libraries, no shortcuts — gave me a solid foundation for understanding how things work under the hood.
